Privacy policy

Effective 1 October 2026

Olwen is a private personal assistant operated by Alex (alxsongs). This policy covers its assistant features, Google Calendar connection and these public information pages. The assistant is intended for its authorised owner; there is no public registration.

Information Olwen accesses

  • Google Calendar: calendar names, identifiers and settings, and event information returned for requested calendars. This can include titles, descriptions, times, time zones, locations, participants, availability, recurrence and event links.
  • Google authorisation: access and refresh tokens that let Olwen use the permissions granted by the owner. Google handles sign-in; Olwen does not receive the Google password.
  • Assistant content: messages, requested notes, tool results and reminder records needed to answer questions or perform the owner's instructions.

How information is used

Calendar access supports agenda questions, availability checks, requested event changes and reminders. The connection requests permission to read calendars and to manage events; Google's event permission includes creating, changing and deleting events. Changes are made through the assistant in response to the owner's instructions. The background reminder service only reads Google events.

Google Calendar information is used for these personal-assistant functions. It is not sold, used for advertising or used to train general-purpose AI models. Olwen's use of Google API data, including any transfer to another service, follows the Google API Services User Data Policy and its Limited Use requirements.

Processing and storage

The configured assistant processes conversations with locally hosted models on the owner's computers. Calendar details used in a conversation can be stored in chat history or tool records. Upcoming-event details are also stored locally as reminders. Notes are stored in the owner's notes app.

Authorisation tokens and application records are held on the owner's server with file and account access controls. The assistant interface uses a private network and authenticated access. Local application records and backups may remain until the owner removes them; there is no automatic deletion period covering all records.

Services that receive information

  • Google receives authentication requests, calendar queries and requested event changes.
  • Phone notifications: the configured ntfy notification service receives reminder text, which can include the event title, time, location and link, to deliver it to the owner's devices. Notification services and devices may retain delivered messages under their own settings.
  • Web research: search providers and visited websites receive search queries and page requests. Personal information included in a search request is sent to those services.
  • Website hosting: these public information pages are hosted on GitHub Pages. GitHub may process normal connection information such as IP addresses and browser details under its privacy statement. These pages contain no calendar records, Google tokens, analytics scripts or advertising trackers.

Google Calendar data is not published to this website. Access to private assistant records is limited to the owner and people the owner authorises to support the installation.

Disconnecting and deleting information

The owner can withdraw access in Google Account connections by removing Olwen's connection. The local Google Calendar connector and reminder sync can also be disabled. Disconnecting stops future access; it does not automatically erase information already saved locally or notifications already delivered.

To remove saved information, the owner can delete the relevant conversations, notes and reminders and remove local authorisation tokens. Removing all retained copies may also require deleting backups and notification history. Deleting a local reminder or chat does not delete the original Google Calendar event; event deletion is a separate action.

Contact and changes

For privacy questions or deletion assistance, contact Alex using the user support email shown on Olwen's Google authorisation screen. This policy will be updated if the installation's data practices change. A new use of Google data will be disclosed and any necessary permission obtained before that use begins.
